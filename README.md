# CodingZen — Website Rebuild

Modern Next.js rebuild of [codingzen.in](https://codingzen.in/) — coding classes for kids, teens, and parents.

## Stack

- Next.js (App Router) + JSX
- Tailwind CSS v4
- Framer Motion / Motion
- GSAP + ScrollTrigger
- React Bits (Aurora, SpotlightCard, Magnet, TrueFocus, CountUp, ScrollReveal, …)
- Lenis smooth scroll
- OGL (Aurora WebGL)

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the next free port).

## Structure

- `src/app` — layout, homepage, SEO (`robots`, `sitemap`)
- `src/components/sections` — homepage sections
- `src/components` — React Bits + layout/effects
- `src/data/site.js` — copy & content from the live brand

## Design direction

Calm “code dojo” zen: soft mist backgrounds, brand ember red, jade accents, mono code moments, expressive display type (Bricolage Grotesque).
